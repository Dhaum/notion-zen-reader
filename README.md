# 📖 노션 지식 리더 (Notion Zen Reader PWA)

> **알도큐브 iPlay 60 mini pro(8.4인치) 최적화 노션 지식 리더 및 독립 학습 트래커**  
> 노션 계정 로그인 없이 안전하게 지식을 읽고, 노션 원본은 단 1비트도 건드리지 않으면서 독자적 클라우드에 학습 기록(회독수, 일자, 체류 시간)을 자동 누적합니다.

---

## 🌟 핵심 특징

1. **Notion 원본 100% 무손상 (Zero Write)**:
   - Notion API는 오직 **'콘텐츠 읽기(Read-only)'** 권한만 사용합니다.
   - 노션 DB의 본문, 속성, 구조는 물리적으로 절대 수정되지 않습니다.
2. **태블릿 제로 트러스트 (Zero Notion Auth)**:
   - 알도큐브 태블릿에는 노션 계정/비밀번호/토큰이 전혀 저장되지 않습니다.
   - 4자리 보안 PIN 번호(기본값: `1234`)로 웹앱만 잠금 해제하여 사용합니다.
3. **8.4인치 태블릿 맞춤형 가독성**:
   - 눈이 편한 다크 모드, 종이 라이트 모드, 세피아 모드 지원.
   - 글자 크기 3단계 조절 및 최적의 줄간격(1.85).
   - **노션 토글(Toggle) 접기/펴기 완벽 지원**: 클릭하여 암기 셀프 테스트 가능.
4. **신중한 1회독 체크인 (False-Positive 방지)**:
   - 단순 스크롤이나 일시적 열람으로 회독수가 오인 누적되는 것을 원천 차단합니다.
   - 본문 최하단의 `[✅ 오늘 공부 완료! 1회독 추가]` 버튼을 누르거나, 독서 타이머 체류 후 확정 시에만 독립 학습 기록으로 인정됩니다.
5. **독립 학습 추적 & 데스크탑 대시보드**:
   - 데스크탑에서 접속하면 **최근 90일 복습 잔디(히트맵)**, **문서별 누적 회독수**, **에빙하우스 망각 곡선 복습 추천 큐**를 한눈에 모니터링할 수 있습니다.
6. **오프라인 PWA 지원**:
   - 서비스 워커를 통해 한 번 열어본 문서는 인터넷이 없는 야외나 비행기 안에서도 즉시 열람 가능합니다.
   - 오프라인 상태에서 기록된 학습 로그는 나중에 와이파이가 연결될 때 자동으로 일괄 동기화됩니다.

## 🚀 빠른 시작 (로컬 실행)

```bash
# 1. 의존성 설치
npm install

# 2. 로컬 개발 서버 가동
npm start
```

* 브라우저에서 `http://localhost:3000` 접속.
* 기본 PIN 번호: **`1234`** 입력 후 입장.
* *(초기 실행 시 NOTION_API_KEY가 없어도 고품질 샘플 지식 노트로 모든 기능이 즉시 구동됩니다.)*

## 🔑 내 실제 노션 지식 DB 연결 방법 (3분 컷)

### 1단계: 노션 읽기 전용 API 키 발급
1. [Notion Developers](https://www.notion.so/my-integrations)에 접속하여 **[+ 새 API 통합 만들기]**를 누릅니다.
2. 이름: `Zen Reader (Read-Only)`
3. **기능 권한(Capabilities)**:
   * **콘텐츠 읽기(Read content)**: ✅ **체크**
   * 콘텐츠 업데이트(Update content): ❌ **체크 해제**
   * 콘텐츠 삽입(Insert content): ❌ **체크 해제**
   * 사용자 정보: ❌ **체크 해제**
4. 생성된 **내부 통합 비밀 토큰 (Internal Integration Secret)**을 복사합니다 (`ntn_xxxx...`).

### 2단계: 내 노션 DB에 연결 공유
1. 데스크탑 노션에서 내가 사용하는 **[제2의 뇌 지식 데이터베이스]** 페이지를 엽니다.
2. 우측 상단 `···` ➔ `연결(Connect to)` ➔ 방금 만든 `Zen Reader`를 선택하여 추가합니다.
3. 데이터베이스 URL에서 32자리 ID를 복사합니다:
   * URL 예: `https://www.notion.so/myworkspace/a1b2c3d4e5f6...7890?v=...`
   * `myworkspace/` 바로 뒤의 **32자리 영문/숫자**가 `NOTION_DATABASE_ID`입니다.

### 3단계: 환경변수 설정
프로젝트 루트의 `.env.example`을 복사하여 `.env` 파일을 생성하고 값을 입력합니다:

```env
NOTION_API_KEY=ntn_xxxxxx
NOTION_DATABASE_ID=a1b2c3d4e5f6xxxxxx
PIN_CODE=1234
```

## 📱 알도큐브 iPlay 60 mini pro에 PWA 앱으로 설치하기

1. 태블릿의 **크롬(Chrome)** 브라우저를 켭니다.
2. 배포된 웹앱 주소(또는 동일 와이파이 내 PC IP 주소: `http://192.168.x.x:3000`)로 접속합니다.
3. 브라우저 우측 상단 **점 3개(⋮)** 메뉴 ➔ **[홈 화면에 추가]** 또는 **[앱 설치]**를 터치합니다.
4. 태블릿 바탕화면에 **`[지식 서재]`** 아이콘이 생성됩니다.
5. 앱을 누르면 상단 주소창이 사라지고 **전체화면 전자책 앱**으로 구동됩니다.

## ☁️ Vercel 무료 클라우드 배포 (전세계 어디서나 접속)

1. 이 저장소를 본인의 GitHub 저장소로 푸시합니다.
2. [Vercel](https://vercel.com/) 대시보드에서 `Add New Project` ➔ 해당 저장소를 선택합니다.
3. **Environment Variables**에 위 3가지 값을 입력합니다:
   * `NOTION_API_KEY`
   * `NOTION_DATABASE_ID`
   * `PIN_CODE`
4. **Deploy** 버튼을 누르면 1분 만에 `https://my-zen-reader.vercel.app` 형태의 나만의 주소가 발급됩니다!
